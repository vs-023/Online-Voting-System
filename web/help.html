Help & Support Center

Need Assistance?

The Help Center is designed to assist voters and administrators in using the Online Voting System effectively. Users can find guidance related to registration, login, voting procedures and account support.

User Guidelines

  • Register using valid voter credentials.
  • Use correct email ID and password while logging in.
  • Each voter is allowed to vote only once.
  • Do not share login credentials with anyone.
  • Verify candidate details carefully before voting.
  • Logout securely after completing the voting process.

Common Issues

  • Forgot password or login credentials
  • Unable to access voter dashboard
  • Duplicate registration issues
  • Incorrect voter information entered
  • Internet connectivity problems during voting
  • Vote already submitted notification

Security & Privacy Tips

  • Keep your password confidential.
  • Never allow others to vote using your account.
  • Always use secure internet connections.
  • Ensure logout after voting completion.
  • Your vote remains private and encrypted.
